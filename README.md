# Idol Camera Web App

A web application that allows you to take photos with your favorite idol!

## Features
- **Camera Feed**: Uses your device's camera (front or back).
- **Idol Overlay**: Upload any transparent PNG of your idol.
- **Adjustable**: Drag to move and use the slider to resize the idol.
- **Capture**: Takes a high-quality photo combining the camera feed and the overlay.
- **Privacy**: All processing happens on your device. No images are uploaded to a server.

## How to Use
1. Allow camera permissions.
2. Click "Upload Idol" to select an image (transparent PNG recommended).
3. Drag and resize the idol to pose with them.
4. Click the capture button to save the photo!

## Deployment
To use this on a mobile device, this site must be served over HTTPS.
GitHub Pages is a great free option.
